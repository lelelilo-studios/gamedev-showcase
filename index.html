Ten game-dev tools, pressed into ten games you can play.

Physics, destruction, fire, crowds, procedural maps, level geometry, level of detail and branching story, plus two agent skill packs that make a coding agent work like a game team. Each tool came from a research wiki of saved game-dev repos and became an original browser game, built with the tool itself by Claude Code. Every cartridge ships with its manual: the exact prompt, the steps and the snags.

How it was made

One Claude Code session (Claude Opus 5.5) chose the ten from a personal wiki of saved posts and repos, wrote a brief for each game and ran ten builder agents in parallel, one game each. For the two skill packs, the skills’ own text was downloaded at a fixed commit and checked first, then followed; nothing from those repos was installed or run. Every game was played to its end screen in headless Chrome, with real key presses, clicks and taps, at desktop and phone sizes.

Fine print

An independent, unofficial showcase. It isn’t affiliated with or endorsed by the makers of any of these tools, and every place, character and company in the games is fictional. Stars and licences are from the wiki snapshot of 2026-10-16.

Code in this repo is MIT licensed. Libraries load from CDNs under their own licences; see credits. The sister collection is the Front-End Cabinet: twenty front-end tools, twenty sites.
