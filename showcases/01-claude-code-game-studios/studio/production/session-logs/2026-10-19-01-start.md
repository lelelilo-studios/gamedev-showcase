## The engine (a departure)

`/start` does not ask about the engine; `/setup-engine` does, and it only configures Godot, Unity
or Unreal (its WebSearch version lookup, engine-reference docs and project scaffold all assume one of
them). The human's answer for this project is **none: a plain web page with Canvas 2D**.

- **Why:** the game ships as one folder in a static showcase site: GitHub Pages, no build step, no
  plugin, and it must also open from disk. A one-screen 2D game does not need an engine, and any of
  the three would ship a multi-megabyte WebAssembly export for it.
- **What it costs:** step 2 of the path is not run. No `docs/engine-reference/`, so every story's
  engine risk reads `NOT ASSESSED`; no engine specialist reviews the code; no parse check exists.
  The run-and-observe rule still applies: every story is launched in a real browser and looked at.
- **Recorded:** by hand, in `project.yaml` under `engine`, `code_root` and `commands.run`.
